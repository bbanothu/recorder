# v3.2.0 streaming master encode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Feed one long-lived ffmpeg child per session with live s16le/48 kHz/mono PCM so `/stop` no longer spends ~37 s per hour encoding and no ~1.38 GB/h float32 mix temp ever exists.

**Architecture:** `MasterMix` loses its sparse-file positional write and gains a sequential frame cursor (one `Float32Array` accumulator per 20 ms frame, flushed through `softLimitToInt16` + a JS downmix) writing into a pluggable **frame sink**: a `stream-encode` ffmpeg child (default) or the existing legacy sparse-temp → WAV → one-shot ffmpeg path (fallback). Equal input produces byte-identical output: the frozen golden stereo fixture pins the timeline, and the mono stream is its pinned downmix.

**Tech Stack:** Node.js ≥ 22.13 ESM, `node:child_process` pipes, ffmpeg (`libopus`, voip, mono), `node --test`, bash harness. Dev host is Windows/git-bash; production is the Debian-slim image with compose `init: true` (tini).

Spec: `.project/specs/v3.2.0-streaming-encode.md` (decisions D1–D9, AC1–AC12).

## Task 1 — `src/stream-encode.js`: the ffmpeg child and its pump

**Files:** `src/stream-encode.js` (new), `test/stream-encode.test.mjs` (new).

Everything here is tested with an injected fake child — **no test may spawn a real
ffmpeg** (the repo's DI rule for IO).

1. **RED (args builder)** — `buildStreamFfmpegArgs(partialOggPath, bitrate)` returns exactly:
   `['-y','-hide_banner','-loglevel','error','-f','s16le','-ar','48000','-ac','1','-i','pipe:0','-c:a','libopus','-b:a',bitrate,'-application','voip','-f','ogg',partialOggPath]`.
   Cases: the default bitrate; a custom `'32k'`; the partial path appears verbatim; `-ac 1` and `-application voip` are present (the AGENTS.md hard constraint, pinned as an assertion so a future "quality" edit fails the suite).
2. **RED (pump + framing)** — `createStreamEncoder({ dir, stamp, bitrate, spawn, log })` → `{ writeMonoFrame(int16), writeZeroFrames(n), finish(), abort(), state() }`:
   - `writeMonoFrame` writes exactly 1920 bytes (960 s16 samples) to the child's stdin; a wrong-length buffer throws (a programming error, not a session failure);
   - a fake child whose `write` returns `true` receives frames in order; a fake whose `write` returns `false` until `'drain'` is emitted receives them after the drain, in order;
   - `pendingPcmBytes` tracks un-drained PCM; `MAX_PENDING_PCM_BYTES` (4 MiB) is exported; when a frame would exceed it, the frame is replaced by silence, `droppedPcmFrames` increments, and **the cursor still advances** (assert the written byte count grew by one frame);
   - `writeZeroFrames(150000)` (50 min of silence) does not allocate per-frame buffers (assert with `process.memoryUsage().heapUsed` bounded, or by asserting a single reused buffer identity) and drains progressively;
   - `state()` → `{ framesFed, outputBytes, alive, fallback, droppedPcmFrames, pendingPcmBytes }` with `outputBytes` read via an injected `statSize` (never a real `statSync` in tests), `null` on throw;
   - `finish()`: `stdin.end()`, awaits `'exit'`; exit 0 → resolves the final path and renames `partial` → `ogg` through an injected `renameFile`; non-zero exit → still renames (D4) and logs a truncation line; the exit deadline (`STREAM_EXIT_TIMEOUT_MS`, 10 s) kills and then renames;
   - `abort()`: kills the child, unlinks the partial, never throws.
   - **The signal helper** — `shutdownStreamEncoder(encoder, { timeoutMs, setTimer, clearTimer, exit })`: ends stdin, waits bounded (`SIGTERM_GRACE_MS` 3 s), then calls `exit(0)`; pinned so a wedged child cannot hang the process.
3. **GREEN** — implement; spawn options `stdio: ['pipe','ignore','pipe']` with stderr drained into a bounded (≤8 KB) ring buffer that is logged on unclean exit (an undrained stderr pipe stalls the child — pin it with a fake that emits a large stderr burst).
4. Report the exact child-API surface the fake must implement, so Task 3's integration test does not rebuild it.

**Commit:** `feat: add the streaming ffmpeg encoder with a bounded backpressure pump`

## Task 2 — `MasterMix`: frame-oriented mixing, two sinks, golden equivalence

**Files:** `src/master-mix.js`, `test/master-mix.test.mjs`.

The highest-risk task in the release: the timeline moves from file offsets to feed order.
**No ffmpeg here** — this task proves the mixer, not the encoder.

1. **RED (frame cursor + gaps)** — with the injected clock and a stub sink:
   - `frameIndex = max(round((atMs - t0)/20), state.lastFrame + 1)`;
   - a packet targeting frame 100 after frame 3 produces exactly 96 zero frames and then the packet's frame;
   - two packets landing on the same frame sum into that frame (assert the flushed sum);
   - a late packet whose clamped index is behind the cursor merges forward into the next unwritten frame; more than `LAG_TOLERANCE_FRAMES = 5` behind ⇒ dropped, counted in `lateDroppedFrames`, one log line;
   - per-user monotonic clamping is preserved (`state.lastFrame`), asserted across two users.
2. **RED (sink contract + golden)** —
   - the **stereo** soft-limited PCM stream for the scripted golden sequence is **byte-identical** to `test/fixtures/master-mix-golden.wav`'s data section (AC1's first half);
   - the **mono** stream equals the pinned downmix `((L+R)/2)|0` of that same fixture (AC1's second half);
   - the accumulation stays `Float32Array` per frame: assert an equivalence case with three overlapping packets whose float32 rounding would differ under Float64 (this is why the golden is reproducible).
3. **GREEN** — refactor `push()`/`#reset()` to the frame model; extract today's `#addAt`/`#writeWav`/`encodeToOgg` chain into a **legacy sink** fed by `writeFrame(frameIndex, s16Stereo)` (positional absolute offset preserved); keep `packetCount`, `ioError`, `used`, `mixPath`/`fd` semantics so the existing suite's internals-pinning tests keep passing.
4. The existing 27 `test/master-mix.test.mjs` cases: list the ones you changed and why. The golden byte-for-byte case must **not** change — if it does, the refactor changed the arithmetic and that is a STOP-and-report, not a test update.
5. `npm test` green; `git status --short` does not list the fixture.

**Commit:** `refactor: mix the master on a sequential frame cursor with pluggable frame sinks`

## Task 3 — wire the streaming sink into the session (default path)

**Files:** `src/master-mix.js`, `test/master-mix.test.mjs`, `src/bot.js`, `src/index.js`, `test/bot.test.mjs`.

1. **RED (probe + mode selection)** — `MasterMix.start(atMs, dir)` runs an injectable
   `probeFfmpeg` (default: a bounded `ffmpeg -version` `execFileSync`); `false` ⇒ the
   legacy sink for the whole session + one log line; `true` ⇒ the stream sink with
   `master-<stamp>.partial.ogg` as its target. Cases: probe true/false; the probe is called
   exactly once per session; a throwing probe is treated as false with one log line.
2. **RED (naming)** — the partial path derives from `sessionMasterFile(dir, at)` by
   replacing the trailing `.ogg` with `.partial.ogg`; a session that finalizes cleanly ends
   with exactly one `.ogg` and **no** `.partial.ogg` in the directory.
3. **RED (encodeState)** — `encodeState()` returns `{ framesFed, outputBytes, alive, fallback }` live, after a fallback, after a clean finish, and after a failure; `/status` renders it with the method present **and** still works when it is absent (the 3.1.0 fallback shape) — run both.
4. **GREEN** — implement: `start()` selects the sink; `push()` feeds the current frame; `finalize()` flushes the last frame, calls `sink.finish()`, and returns the final `.ogg` path (or `null` on total failure, exactly as today).
5. `npm test` green; report counts and every changed test.

**Commit:** `feat: encode the master mix through a live ffmpeg child by default`

## Task 4 — failure paths: child death, unclean exit, silence-vs-failure

**Files:** `src/master-mix.js`, `test/master-mix.test.mjs`, `src/bot.test.mjs` (delivery contract only).

1. **RED (mid-session death)** — fake child exits non-zero while frames are still arriving:
   the session continues; the sink switches to a legacy sink seeded at the current frame
   index; subsequent audio lands at its correct absolute offsets; the already-streamed
   prefix reads as silence (assert it explicitly — this is D3's documented cost); the
   partial is unlinked; `encodeState()` reports `{ alive: false, fallback: true }`; exactly
   one loud log line names the exit code, the stderr tail and the prefix loss.
2. **RED (unclean exit at finish)** — child exits non-zero during `finish()`: the partial is
   renamed to `.ogg`, a truncation line is logged, and the path handed back ends in `.ogg`.
   Pin that a `.partial.ogg` is **never** the return value of `finalize()` in any case (AC6).
3. **RED (silence vs failure)** — the `masterHadAudio` contract in its new form: a session
   that fed only silence finalizes to `null` and the bot reports "Nobody spoke"; a session
   that fed audio but could not produce a master (`ioError`/both paths dead) reports
   `masterWriteFailedText`. Assert through `src/bot.js:501-512`'s read, not by reading the
   code.
4. **GREEN** — implement the fallback swap, the salvage rename, the `ioError` preservation,
   the counters (`lateDroppedFrames`, `droppedPcmFrames`) and the `finalize()` summary log.
5. **Carry-in for the docs (Task 7):** the exact user-visible consequence of a mid-session
   child death (silent prefix) and the truncation case, in one line each.
6. `npm test` green; report counts and every changed test.

**Commit:** `fix: fall back to the legacy master path when the encoder dies mid-session`

## Why these decisions (for the reviewer)

| Decision | Alternative rejected | Cost of the rejected option |
|---|---|---|
| Sequential frame cursor + two sinks (D1) | keep the sparse file and pipe it into ffmpeg at finalize | keeps the 37 s wait and the 1.38 GB/h temp — the whole point of the release |
| Float32 per-frame accumulator | Float64 (cleaner arithmetic) | breaks byte-equality with the frozen golden fixture, losing the only timeline guard |
| Silence-substitution under backpressure (D2) | skip frames to relieve the pipe | shifts every later timestamp — a silent, unfixable transcript corruption |
| Legacy fallback on child death (D3) | abort the master | a two-hour meeting loses its audio |
| Salvage the partial on unclean exit (D4) | refuse to deliver anything | discards a playable file that is already on disk |
| Accept the 25 MB cap (D6) | pick the bitrate at session start from history | new persisted per-guild state for a case that only bites beyond ~2.4 h |
| Merge late frames forward, drop beyond 100 ms (D7) | recreate the hole by seeking | a pipe cannot seek; dropping silently corrupts timing |
